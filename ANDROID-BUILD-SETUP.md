# Gita AI Android Build

## App Details
- App Name: Gita AI
- Package ID: com.micsal.gitaai
- Website: https://gita-ai-1.onrender.com/
- Build Type: Trusted Web Activity (TWA)

## Build APK
1. Open GitHub repository.
2. Go to Actions.
3. Select Build Gita AI Android App.
4. Click Run workflow.
5. Wait for the build to finish.
6. Download the gita-ai-android-build artifact.
7. Extract the ZIP and install the APK on Android.

## Important
This is a test APK. Play Store publishing requires a permanent signing key and Digital Asset Links verification.
